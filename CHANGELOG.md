# Changelog

## 1.2.1

- Контекст результата по умолчанию: независимый первый цикл, последние 3 цикла и реплики пользователя.
- Переключатель переименован в «Использовать весь контекст дискуссии»; при его включении настройка числа последних циклов скрывается.
- Все секции настроек открываются свёрнутыми и работают как аккордеон: открытие следующей секции закрывает предыдущую на том же уровне.
- Карточки моделей также открываются по одной; модели визуально разделены линиями.
- Счётчики с кнопками «− / +» выровнены симметрично относительно числа.
- README сокращён до основных возможностей и принципа работы.
- CI подготовлен для постоянной release-подписи через GitHub Secrets.

## 1.2.0 — 2026-10-04

- Первый цикл дискуссии стал полностью независимым: модели не видят ответы друг друга в этом цикле.
- Со второго цикла начинается взаимная критика и улучшение решений.
- Добавлено раннее завершение дискуссии через безопасную двухшаговую схему ACTIVE → DONE_PENDING → DONE; служебные маркеры скрыты от пользователя.
- Максимальное количество циклов теперь является верхним пределом; значение по умолчанию — 10.
- Когда остаётся одна активная модель, она получает последний содержательный ход перед завершением дискуссии.
- Пользовательская реплика во время дискуссии возвращает выбывшие модели в активное состояние.
- Добавлена отдельная настройка контекста модели результата: вся дискуссия используется по умолчанию, а число последних циклов остаётся видимым и по умолчанию равно 3.
- Первый независимый цикл сохраняется в контексте результата даже при ограничении последними N циклами.
- Добавлены отдельные редактируемые промпты первого и последующих циклов со сбросом к значениям по умолчанию.
- Добавлены streaming-ответы, Markdown, таблицы и индивидуальные цвета сообщений моделей.
- Длинное нажатие непосредственно по Markdown-тексту открывает копирование ответа и режим выделения текста.
- Для OpenRouter добавлен интернет-поиск с движками Auto, Native, Parallel, Perplexity и Exa, настраиваемым лимитом вызовов и обработкой временных ошибок backend.
- Улучшено определение возможностей reasoning, включая модели с обязательным reasoning, и сделаны более понятные сообщения об API-ошибках.
- Вложения в composer показываются компактно как «Вложения N»; список раскрывается вертикально и позволяет удалить любой файл отдельно.
- Настройки переработаны в разворачиваемые группы: участники, параметры дискуссии и «О приложении».
- Все модели, включая модель результата, объединены под «Участники дискуссии»; шапка каждой модели кликабельна по всей площади.
- «Параметры дискуссии» объединяют циклы и порядок участников, промпты циклов и контекст результата.
- В «О приложении» перенесены сведения о защите API-ключей, фоновой работе, сбросе настроек, версии и репозитории.
- Добавлены системные действия для исключения приложения из оптимизации батареи и перехода к настройкам фоновой работы.
- Обновлена контрастная тёмная цветовая схема для лучшей читаемости.
- Зона начала свайпа открытия боковой панели увеличена до 80% ширины экрана.
- Обновлена иконка приложения и выполнена серия UI-полировок.

## 1.1.0

- Native Jetpack Compose interface; WebView is no longer used by the application.
- Responsive swipe drawer with chat search, new chat, pin/rename/delete and settings.
- Elastic 2+ model discussions plus an independent result model.
- Cycle count and first responder moved to General settings.
- Pause/continue and stop are integrated directly into the composer; Stop replaces Send while a cycle is active.
- Persistent on-demand attachments shared by all participants without resending file contents on every request.
- Independent per-model prompt, optional temperature, timeout and capability-aware reasoning controls.
- Result model can evaluate the whole discussion or the last N cycles while always retaining user interventions.
- API keys encrypted with AES/GCM using Android Keystore; backups remain disabled and redirects/unsafe keyed HTTP are blocked.
- Settings reset moved to General settings with confirmation; chat history is preserved.
