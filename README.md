# DisputeAI

Android-приложение для общего чата с двумя независимыми LLM.

Основная идея: две модели видят одну историю разговора и отвечают по очереди в режиме цикла. Пользователь может поставить цикл на паузу, прочитать ответы, вставить свою реплику или вложение и продолжить.

## Что уже реализовано

- две независимо настраиваемые модели;
- только режим «Цикл»: количество циклов, пауза и остановка;
- пользовательская реплика на паузе учитывается обеими моделями;
- вложения остаются в истории до очистки чата;
- тяжёлое содержимое вложений не отправляется при каждом запросе: модель видит каталог и запрашивает конкретный файл только при необходимости;
- текстовые файлы, изображения и PDF;
- сворачиваемые настройки каждой модели и общие настройки;
- в шапке показываются только пользовательские имена моделей, без ID;
- для OpenAI-совместимых API не задаётся искусственный `max_tokens`; при обрыве по лимиту провайдера приложение автоматически запрашивает продолжение;
- API-ключи шифруются AES/GCM, мастер-ключ хранится в Android Keystore;
- ключи не попадают в историю и экспорт;
- резервное копирование приватных данных отключено;
- API-ключи не отправляются по HTTP; незашифрованный HTTP допускается только для локальной сети без ключа;
- внешняя навигация WebView блокируется.

## Сборка

Проект собирается обычным Android Gradle Plugin. CI публикует debug APK как артефакт GitHub Actions.
